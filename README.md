# ReactJS Task Tracker Application with Redux

A daily task planner built with React, Redux Toolkit, and Vite.

## Features

- Plan tasks for any date using a calendar-style date picker.
- Mark tasks complete for each specific day.
- Close the current day to automatically shift incomplete tasks into tomorrow.
- Keep a daily history record with planned/completed/shifted totals.
- Automatically save planner data in localStorage so day/task records stay available after refresh.

## Run locally

```bash
npm install
npm run dev
```

Then open the URL shown by Vite (typically `http://localhost:5173`).

## Build and preview production

```bash
npm run build
npm run preview
```
